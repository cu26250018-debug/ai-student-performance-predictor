# ai-student-performance-predictor
An AI-based student performance prediction system using Python and Machine Learning.
💻 Source Code

The complete source code for this project is available below.

- Main Application: "View app.py" (./app.py)
- Dataset: "View student_performance.csv" (./data/student_performance.csv)
- Dependencies: "View requirements.txt" (./requirements.txt)

Technologies Used

- Python
- Machine Learning
- Scikit-learn
- Pandas
- Streamlit
- Matplotlib

How to Run

Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
